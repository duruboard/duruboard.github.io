      개체 (1)

      그래프·표 추가

      1 유형

      그래프의 형태를 고릅니다. 세로 막대는 항목이 적을 때, 가로 막대는 항목이 많거나 이름이 길 때, 꺾은선은 순서가 있는 항목(1단원→6단원)의 흐름을 볼 때 적합합니다. 히스토그램은 값이 어느 구간에 몰려 있는지, 표는 값을 그대로, 명단은 해당 항목을 목록으로 보여 줍니다.

      2 X축 항목

      막대 하나가 무엇인지 고릅니다. 카드 아래의 회색 글자는 실제로 막대에 붙을 이름입니다. ‘학번별’은 학생마다, ‘반별’은 같은 반 학생을 묶어 반마다, ‘단원별’은 아래에서 고른 단원(예: 1단원~6단원)마다 막대 하나를 표시합니다. 축 이름은 그래프에 표시되는 이름이며, 비워 두면 자동으로 정해집니다.

      항목 기준

      축 이름
      항목 순서

      3 Y축 값

      그래프에서는 막대 높이로, 통계에서는 숫자 하나로 나타낼 값을 정합니다. 학번처럼 행을 X축에 놓았다면 여기서 계산에 쓸 열(예: 1단원~6단원)을 고르고, 열을 X축에 놓았다면 계산 방식만 고르면 됩니다(예: 입력률). ‘입력 칸 수’는 값이 들어 있는 칸, ‘미입력 칸 수’는 빈칸의 수이며, 0과 거짓도 입력된 값으로 봅니다.

      축 이름

      1 열 선택

      계산에 사용할 열을 고릅니다. 예: 1단원~6단원. ‘전체 선택’은 학번·이름 같은 식별 열을 제외하고 선택합니다. 열을 길게 누르거나 마우스 오른쪽 단추를 누르면 자료형(수치·문자 등)을 변경할 수 있습니다.

      사용할 열

      2 계산

      먼저 계산 방향을 고릅니다. ‘열마다’는 열(세로줄)마다 값 하나(예: 단원별 완료율), ‘행마다’는 행(가로줄)마다 값 하나(예: 학생별 진도율), ‘전체 하나로’는 선택한 모든 칸을 값 하나(예: 전체 진도율)로 계산합니다. 다음으로 계산 방식을 고릅니다. ‘입력 칸 수’는 값이 들어 있는 칸, ‘미입력 칸 수’는 빈칸의 수이며, 0과 거짓도 입력된 값으로 봅니다. 산출 범위로 상위·하위 일부나 기준값 이상·이하만 산출할 수 있습니다.

      계산 방향
      계산 방식

      산출 범위상위·하위 일부만 산출

      3 조건

      조건에 맞는 행만 골라 계산합니다. [조건 추가]를 누르고 기준 열을 고른 뒤, 문자 열은 값을 체크하고(예: 반 2-1), 숫자 열은 범위를 지정합니다(예: 정답률 0 ~ 70). 한 열에서 여러 값을 고르면 그중 하나라도 해당하는 행, 조건이 여러 개이면 모두 만족하는 행을 씁니다. 산출 범위로 계산 결과의 상위·하위 일부만 남길 수도 있습니다.

      개체 추가 사용 안내

      1. 열 선택계산에 사용할 열을 고릅니다. 예: 1단원~6단원
      2. 계산계산 방향(열마다·행마다·전체 하나로)과 방식(평균·합계·최댓값·최솟값·입력 칸 수·입력률·미입력 칸 수)을 고릅니다. 예: 학생별 진도율 = 행마다 · 입력률 ‘학번별 입력률(%)’ → 학생마다 막대 하나, 입력된 단원의 비율(진도율) ‘열별 입력 칸 수’ → 단원마다 막대 하나, 입력한 학생 수
      3. 조건열별로 조건을 걸어 계산할 행을 고릅니다. 문자 열은 값 체크, 숫자 열은 범위 지정. 예: 반 2-1, 정답률 0 ~ 60.
      4. 표시막대·꺾은선·히스토그램·표·명단 중에서 고르고, 최저값·최고값을 강조할 수 있습니다. 명단은 행마다 계산에서 해당 행을 목록으로 보여 줍니다.

      표로 전환 미리보기 오른쪽 아래의 [표로 전환]을 누르면 그 자리에 자료 표가 표시되며, 선택한 열과 계산 결과가 색으로 구분됩니다. [미리보기로 전환]을 누르면 돌아갑니다.
