두루보드

받은 자료를 그래프와 통계로
손쉽게 정리하는 교실용 현황판입니다.

두루보드 시작

이용 순서

  1. 1

    자료 연결

    도메인과 인증코드를 입력하고 자료를 조회합니다.

  2. 2

    개체 구성

    그래프 또는 통계를 고르고, 위쪽 미리보기를 보며 축과 조건을 설정합니다.

  3. 3

    현황 확인

    보드에 모인 개체로 학급 현황을 한눈에 확인합니다. 구성한 배치는 파일로 공유할 수 있습니다.

활용 예시

학생별 진도율

학생마다 입력된 칸의 비율을 막대로 표시합니다.

단원별 해결률

해결률이 가장 낮은 단원을 강조해 표시합니다.

미해결 학생 명단

특정 단원을 해결하지 않은 학생을 목록으로 추립니다.

78.9

반별 평균 정답률

조건에 맞는 행만 골라 하나의 수치로 산출합니다.

안심 사항

  • 인증코드는 화면을 닫으면 사라지며, 저장하지 않습니다.
  • 받은 자료는 이 기기 화면에만 표시합니다. 분석 파트너(AI)를 사용하는 경우에만, 교사가 정한 범위의 자료를 선택한 AI 공급자에게 전송합니다.
  • 분석 파트너로 보내는 자료 중 학번 등은 가명(ID-01 등)으로 바꾸어 보낼 수 있으며, 원래 값은 이 화면에서만 확인합니다.
  • 자료에 포함할 정보는 자료 제공자(교사)가 결정합니다.

AI 인증 키 보관

분석 파트너에 쓰는 AI 인증 키는 레이아웃 내보내기에 포함되지 않으며, 실행 방식에 따라 아래와 같이 보관합니다.

Google Apps Script 웹 앱에서 열 때

인증 키를 웹 앱(스크립트 속성)에 보관하고, AI 요청도 웹 앱이 대신 보냅니다. 키가 교사 화면으로 전달되지 않으며, 한 번 저장하면 PC와 휴대폰 어디서든 다시 입력하지 않습니다.

두루보드 주소로 열 때

설정에서 보관 방식을 고릅니다.

  • 저장 안 함 페이지를 닫으면 삭제 (기본)
  • 이 탭 동안 탭을 닫으면 삭제
  • 기기에 잠금 저장 지문·얼굴·PIN으로 잠가 이 기기에 30일간 보관, 사용할 때 같은 방법으로 해제

잠금 저장은 지원하는 브라우저·기기에서만 선택할 수 있으며, 개인 기기에서만 사용하십시오. 휴대폰에서는 카카오톡 등 앱 안이 아닌 사파리·크롬에서 여십시오.

어느 방식이든 두루보드 전용 키를 발급하고, 공급자 화면에서 사용 한도를 설정하여 사용하십시오.

연동 방식

일반 서버

자료 제공 서버가 아래 주소로 표 형태의 자료를 응답하면, 두루보드에서 도메인과 인증코드를 입력하여 사용합니다.

GET https://{도메인}/api/v1/data
Authorization: Bearer {인증코드}
Google Apps Script 웹 앱

웹 앱이 두루보드 화면을 불러와 보여 줍니다. 웹 앱 주소 뒤에 ?view=duruboard를 붙여 열고 [불러오기]를 누르면 됩니다.

https://script.google.com/…/exec?view=duruboard

학교 계정 로그인으로 확인하므로 인증코드가 필요 없고, 기존 배포를 그대로 사용합니다. 웹 앱에서 허용한 교사 계정만 자료를 볼 수 있으며, 분석 파트너의 AI 인증 키도 웹 앱에 보관됩니다.

어느 방식이든 응답에 포함할 정보는 자료 제공자(교사)가 결정합니다.

기존 시스템 연결

이미 운영 중인 사이트나 시스템을 두루보드와 연결하려면, 생성형 AI(코딩 도우미)에게 기존 시스템의 소스 코드와 함께 아래 요청문을 전달하십시오.

요청문은 고칠 필요 없이 그대로 보내면 됩니다. AI가 소스 코드에서 전송할 수 있는 자료를 찾아 목록으로 보여 주고 어떤 자료를 보낼지 물어보므로, 그때 고르십시오. 사용 기술 파악, 인증코드 발급과 연결 정보 안내도 규격 문서의 작업 지시에 들어 있습니다.

아래 두루보드 규격 문서의 '0. AI 코딩 도우미에게'에 따라 이 시스템에 두루보드 연결 기능을 추가해 주십시오.

(이어서 두루보드 규격 문서 전문)

[요청문 복사]를 누르면 위 요청문과 함께 규격 문서 전문(약 13,000자)이 한 번에 복사됩니다. AI 채팅창에 그대로 붙여 넣으면 되며, AI가 웹 주소를 열 수 없어도 진행됩니다. Google Apps Script 웹 앱이면 AI가 위 '웹 앱 안에서 열기' 방식으로 구현합니다.

자료 제공 서버의 도메인과 인증코드를 준비한 뒤 시작하십시오. Apps Script 웹 앱은 웹 앱 주소에 ?view=duruboard를 붙여 여십시오.
