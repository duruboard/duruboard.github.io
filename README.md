# 두루보드 자료 제공 규격

[두루보드](https://duruboard.github.io/)는 교사가 받은 자료를 그래프와 통계로 정리하는 교실용 현황판입니다. 이 저장소에는 두루보드 화면과, 기존 사이트나 시스템이 두루보드에 자료를 보내기 위해 지켜야 할 규격이 들어 있습니다.

- 규격 문서: [API_SPEC.md](API_SPEC.md)

## 생성형 AI(코딩 도우미)에게 맡기는 방법

기존 시스템의 소스 코드와 함께 아래 요청문을 그대로 전달하십시오. 어떤 자료를 전송할지는 AI가 후보를 보여 주며 물어봅니다.

```
아래 주소의 두루보드 규격 문서를 읽고, '0. AI 코딩 도우미에게'에 따라 이 시스템에 두루보드 연결 기능을 추가해 주십시오.
규격 문서: https://duruboard.github.io/API_SPEC.md
```
